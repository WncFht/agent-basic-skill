# Production Defaults

Treat frontend work as production-facing unless the user explicitly asks for a demo, wireframe, low-fidelity sketch, teaching example, or component gallery.

## Defaults

- Real users, not reviewers, are the audience.
- The page should look maintainable, not one-off.
- Copy should be short, concrete, and useful.
- Components need a real task or information purpose.
- Empty, loading, form, list, and feedback states should feel product-ready.

## Copy Gate

Visible text should help the user understand:

- current state
- available action
- result
- risk or limitation
- next required step

Remove text that mainly describes visual material, animation, layout craft, or implementation intent.

## Boundaries

Marketing pages may use more atmosphere, but still need a value proposition and conversion logic. Tools, dashboards, data pages, and workbenches should stay direct and task-focused.
