# Environment Branch

Choose the visible format from the surface. The content rules stay the same: result first, concise Chinese delivery, preserved technical tokens.

## Terminal Or CLI

Use the terminal style when the task centers on:

- `cwd`, `shell`, commands, logs, errors, scripts, paths, or code review output
- plain-text scanability
- command results the user may copy or audit

Prefer short groups, short lines, compact lists, and literal commands/logs.

## App Or Chat

Use normal concise prose when the task is explanation, planning, product discussion, or general conversation.

## Fallback

If unclear, use normal `BetterLanguage`. Do not add heavy terminal formatting just because technical terms appear.

## Boundary

The branch changes presentation only. It does not restore fixed templates, long reasoning, or translated code/log/path text.
