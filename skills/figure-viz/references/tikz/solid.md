# solid 语法 — 伪 3D 等距立体块

体积本身就是论证的图：参数化结构（机架、管道、容器）、3D 张量与堆叠块、按层序码放的块体（encoder 层栈、KV cache、适配器堆）。块面关系承载语义时才用；只想「看起来立体」的装饰一律不升维——平面 2D 块能表达的不许进 iso。

## 结构件

- **等距基 `ziso`：** 整个 `tikzpicture`（或局部 `scope`）挂 `[ziso]`——2:1 dimetric，x 轴向右下、y 轴向左下、z 轴直上；视向 (+x,+y,+z)：近角 = 底面前角（六边形轮廓的下尖角），顶面在最高处。基向与光向一经选定全图统一。
- **主体盒 `ssolid=<族色>`：** 一个 pic——`\pic[ssw=..,ssd=..,sst=..] at (P) {ssolid=vteal};`。锚点 P = 底面近角（块立在调用点上）；`ssw`/`ssd`/`sst` 是沿 x/y/z 三轴的名义边长（基向量倍数，几何台账里的轴值，缺省 1/1/1）。顶/左/右三面固定 `!12/!30/!50` 明度比——光源恒定左上，填色由样式钉死（调用点传 `fill` 无效）；描边默认 `ssedge`（`black!55`、0.5pt、round join），`\pic[draw=..,line width=..]` 经 pic actions 覆盖。
- **落地投影 `vshadow`：** `\fill[vshadow] (cx,cy) ellipse (rx and ry);`——bg 层椭圆，色固定 `vgray!30`；`rx≈(ssw+ssd)/2`、`ry≈rx/2` 起步，cy 贴块底微调让下缘露出。投影与 `\draw[ssedge]` 手工补边都是纯坐标无名墨水，coverage 报未埋点属预期——行尾 `% fv:noaudit` 豁免（判据见 coverage.md）。
- **薄板：** `sst` 取小值（如 0.12–0.18）的 `ssolid` 就是平板；多片等距错台堆叠（纸张式）侧面近消失时退回 `tensor.md` 的平行四边形 + 侧唇写法。
- **柱体：** 无 pic——`vizstyle.tex` 注释里有顶椭圆 + 左右壁三段骨架；明度比同盒体（顶 `!12` / 左壁 `!30` / 右壁 `!50`），顶椭圆 `rx:ry = 1.41:0.71`（ziso 下水平圆的自然投影）。
- **厚度/深度箭头：** 沿 z 或顶面轴单独画 `{Stealth}-{Stealth}` 双头线；`varr` 是流向连接器，不借给尺寸标注。

## 规则

- 一个立体块 = 一个语义对象；块色相按族/角色定（颜色即语义），不按视觉位置。同族堆叠可换明度层级，异族换色相。
- 全图只许一个光向、明度比固定 `!12/!30/!50`——自定义面也按此映射；只画看得到的三面（顶、左、右），手画第四面必错（背面看不到）。
- 不与正交 2D 矩形混排同一语义层：一张图要么全 iso 要么全平面；真要混排，iso 件必须是另一个语义层（如底座机架是 iso、上层卡片是平面），并在含义框里点明。
- 堆叠沿 +z：第 i+1 块锚点 = 第 i 块锚点 + `(0,0,sst_i)`——`at` 接受三轴坐标 `at (0,0,0.7)`；锚点先 `\coordinate (N1)` 再 `at (N1)` 更可读。
- 几何台账先行：锚点、三轴长、外接 AABB（公式见骨架节）先算再落笔；等价类（同型层块）必须等大——`ssw/ssd/sst` 相等即天然等大。

## 骨架

```tex
\begin{tikzpicture}[ziso]
  \begin{pgfonlayer}{bg}
    \fill[vshadow] (0.4cm,0.18cm) ellipse (2.8 and 1.05);          % fv:noaudit 整堆共用一个影
  \end{pgfonlayer}
  \coordinate (N1) at (0,0);                                       % 底座近角
  \pic[ssw=2.4,ssd=1.6,sst=0.7] (bk1) at (N1)      {ssolid=vteal};  % pic 必须起名
  \pic[ssw=1.8,ssd=1.2,sst=0.5] (bk2) at (0,0,0.7) {ssolid=vblue};  % +(0,0,sst 下块)
  \pic[ssw=1.8,ssd=1.2,sst=0.5] (bk3) at (0,0,1.2) {ssolid=vviolet};
  % AABB = 六边形轮廓的外接矩形（画布坐标，偏移量必须带单位）：
  %   sw = 锚点 + (-ssw cm, 0)      ne = 锚点 + (ssd cm, sst + 0.5·(ssw+ssd) cm)
  \vzbbox{bk1}{($(N1)+(-2.4cm,0cm)$)}{($(N1)+(1.6cm,2.7cm)$)}[overlap=bk3]
  \vzbbox{bk2}{($(0,0,0.7)+(-1.8cm,0cm)$)}{($(0,0,0.7)+(1.2cm,2.0cm)$)}[inside=bk1]
  \vzbbox{bk3}{($(0,0,1.2)+(-1.8cm,0cm)$)}{($(0,0,1.2)+(1.2cm,2.0cm)$)}[overlap=bk2]
\end{tikzpicture}
```

AABB 左缘 = 锚点 −`ssw`·1cm（左面最左棱）、右缘 = 锚点 +`ssd`·1cm（右面最右棱）、顶缘 = 锚点 +`sst`+0.5·(`ssw`+`ssd`)·1cm（顶面远角，0.5 是 ziso 的 x/y 斜率）、底缘 = 锚点（近角）。带 z 偏移的锚点把三轴坐标直接写进 calc：`($(0,0,0.7)+(-1.8cm,0cm)$)`——三轴部分不带单位（走 ziso 基）、偏移部分必须带单位（走画布），别混。

## 审计埋点处方

- **每块一条 `\vzbbox`** 注册外接 AABB（公式在骨架节）；块内三面是同一语义件的组成面，不单独埋点。`\pic` 上不要挂 `vaudit`——pic 不是 node，不产生审计行。**所以 pic 必须起名 + 配同名 `\vzbbox`**：`\pic (bk1) at .. {ssolid=..}` 搭 `\vzbbox{bk1}{..}{..}`——`ssolid` 不自注册，忘起名或名字对不上，coverage 一律报未埋点（见 coverage.md 的 pic 判据）。
- **无断言节点也要 `vaudit={}`**：claim/mean 框这类不参与任何关系断言的节点同样要挂 `vaudit={}` 占位——空标签合法，只注册盒子进 COLLIDE/NEST；不挂就报未埋点。
- **堆叠关系按 2D AABB 实报**：审计只看 2D 盒，「叠在上面」要么被下块 AABB 罩住、要么相交——上层 AABB 完全落进下层 → `inside=`（被验证的断言，越出即 ERR）；上层探出下层顶缘 → 部分相交 → `overlap=`。不是语义修饰，按几何实写。
- **`overlap=` 是标量**：每盒至多一条；一块同时探出多块时把声明分摊到对端盒（对称判定，任一侧写都豁免整对）——如 bk1 写 `overlap=bk3`、bk3 写 `overlap=bk2`，两对就都有豁免。
- **`tiles=` 不适用**：堆叠块 AABB 是悬空重叠关系不是平面铺砌，写 `tiles=` 只会报「未覆盖孔」。
- **面内文字**：`\node` 落进哪几层 AABB 就给哪几层写 `inside=`（多值合法）——上块 AABB 的下缘常罩住下块面的上半，标签压在线上会被 COLLIDE 拦；跨界的写 `overlap=`，或把标签压到上块 AABB 底缘之下只写一层。
- **厚度/深度箭头**画在 AABB 外（如最左竖棱外侧）配 `\vzwire`；要贴着块画、穿进 AABB 就写 `via=`。
- **投影不埋点**：装饰性椭圆与底座天然重叠，埋了只会收获 NEST/COLLIDE。

## 陷阱

- **基向量必须带单位**：`ziso` 写死 `z={(0cm,1cm)}`——裸 `z={(0,1)}` 会把 z 向量解释成 pt 级（≈1pt），块当场塌成平行四边形；x/y 裸对按 cm 解析、z 不解析，行为不对称，自写变体一律带单位。
- **calc 偏移量的单位**：`($(N)+(x,y)$)` 里不带单位的 `(x,y)` 走 ziso 基向量（不是画布位移），写 AABB 角点必须 `(-2.4cm,0cm)` 这类带单位偏移，或改 `[xshift=..,yshift=..]`。`$(0,0,0.7)$` 这种纯三轴写法反而是对的。
- **光向只有一个**：所有立体件共享顶 `!12` / 左 `!30` / 右 `!50`；要画「光从右来」的块只能重排坐标系，不许单独翻面光——两个光向同框即穿帮。
- **厚度箭头别借 `varr`**：`varr` 是流向连接器（带语义与 `\vzwire` 端点约定）；尺寸标注用 `{Stealth[length=2.4mm]}-{Stealth[length=2.4mm]}` 双头线另画，同样镜像 `\vzwire`。
- **`[scale=]` 不缩立体件**：同其他语法——pic 内文字、线宽、`sst` 比例都会失衡；要整体改大小改几何台账的 `ssw/ssd/sst` 数值。
- **多片等距薄板**（错台半重叠的纸张式堆叠）本质是 tensor 语法：面是平行四边形不是六面体，退回 `tensor.md` 写法 + `overlap=`。
- **AABB 公式随锚点而变**：`ssolid` 的锚点是底面近角；手写三面或柱体时锚点定义不同，外接盒要重算——柱体外接盒 ≈ 顶椭圆盒 ∪ 底椭圆盒的并集。
- 编译需要 `calc` 库（`$(...)$` 偏移语法）；`render_tex.py --frag` 的 preamble 已含。
