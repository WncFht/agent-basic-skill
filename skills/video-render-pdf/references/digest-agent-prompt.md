# 分段精读 subagent prompt 模板

长视频（>20min / >300 条字幕）按 slide 时间轴切段后，每段派一个精读子代理。
此模板在 61min 组会视频上验证过：6 段并行、零返工。方括号是填写槽位。

主代理的责任（别下放）：统一大纲、连贯叙事、跨段去重、终帧裁决。

## 模板

```text
你是视频笔记流水线的分段精读子代理。任务：精读 [平台] 视频「[标题]」（讲者[姓名]）
转写稿的 [HH:MM]–[HH:MM] 段，产出结构化 digest。

转写文件：[绝对路径]/work/transcript_ts.txt（每行 `MM:SS 文本`）。
你的时段切片已备好：[绝对路径]/work/seg_N.txt（由 transcript.py slice 生成，
含 ±15s 重叠）。只读你的切片，不要读全稿。

本段对应的幻灯片内容（供你校正转写讹误）：
[从接触表/scan 图读出的本段 slide 序列：标题 → 要点 → 公式/图表，按时间顺序]

转写质量差，常见讹转：[从标题/描述/领域推断的术语表，如 "EGN=预训练模型、
半寸=微调、Multi-Cast=Multi-Task"——ASR 对中英混排术语会讹，列出猜测映射]
数字与公式必须可自洽复算，对不上的标 [待核]。

输出：写到 [绝对路径]/work/digest/seg_N.md，结构：
1. 本段教学目标与叙事线（3-5 句）
2. 按时间顺序的核心论点清单：每条含【时间戳范围】【论点】【支撑细节（公式/例子/数字）】
3. 讲者强调的重点/直觉解释/易错点提醒（带时间戳）
4. 值得配图的候选时刻（画面内容 + 时间戳）
5. 待裁决疑点（转写不清、数字存疑、与幻灯片冲突处）
6. 讲者提到的论文/作者/年份清单

返回时只需一句话确认文件已写 + 列出待裁决疑点。
```

## 填写要点

- **幻灯片上下文槽位是命门**：转写讹误只能靠画面内容校正。主代理先建
  timeline 接触表、读 sheet 得到每段 slide 序列，再写进 prompt。
- **讹转词表**：ASR 对该领域术语的猜测映射（即便不完全准，子代理
  拿到提示后纠错率显著高于裸转写）。
- **切片文件先行**：`transcript.py slice` 生成 seg_N.txt 写进 prompt，
  子代理不做任何文件截取——否则每个子代理会重造 awk 且容易翻车。
- **输出契约**：digest 写文件、返回只回确认 + 疑点。子代理返回体越小，
  主上下文越省。
- 段数参考：~10min/段；边界按 slide 翻页点切，不按整点切。
