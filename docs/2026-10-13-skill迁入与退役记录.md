# Skill 迁入与退役记录

## 目标与判断条件

将七个现用 skill 发布到 agent-basic-skill，保留完整可安装载荷。成功条件是安装目录包含正文、脚本、参考文件、资源与界面元数据，现役列表和安装文档一致，两个退役 skill 的原文件全部保留。缺少必需载荷、包含凭据或运行缓存、退役 skill 仍可按名称安装均视为失败。安装器既有默认目录保持兼容，通过显式 `--dest-root` 使用共享目录。

## 来源与范围

asr、figure-viz、link-get、paper-search、video-render-pdf、setup-toolchain、skill-management 来源为本机 `~/.agents/skills/` 在 2026-10-13 的现用版本。本机目录继续作为维护事实源，仓库保存发布快照；发布时核对差异，不在两处独立维护。本任务不替换本机已启用 skill。

迁入排除虚拟环境、ASR 模型与下载的二进制、Python 与检查器缓存、paper-search 的 SQLite 缓存和运行日志、video-render-pdf 的临时 bandscan 图片，以及 `.env` 凭据。paper-search 的 OpenReview CSV 快照是原实现指定的版本化数据，保留；`.env.example` 保留为配置模板。

plot-skill 与 report-download 从 `skills/` 原样移至根目录 `vendor/`，退出现役列表和安装入口。plot-skill 的图表用途由 figure-viz 承接；report-download 没有指定替代 skill。

## 安装布局

新增 skill 的依赖声明和跨 skill 调用使用 `~/.agents/skills/<name>/`。安装文档改为显式指定该目录，移除旧的整目录 `rsync --delete` 示例，以免删除目的目录中属于其他来源的 skill。安装器原有默认目录保持不变。

## 验证范围

运行仓库现有测试，核对安装与复制后的载荷；检查七个新增 skill 的 frontmatter 和界面元数据；逐文件比较归档与迁入前的仓库版本；扫描待发布内容中的密钥并检查差异。验证针对归档与发布，不代表已执行所有需要网络、凭据、模型或 LaTeX 环境的端到端工作流。

仓库 12 项测试通过。七个新增 skill 均通过安装器安装到临时目录，两个退役名称均返回 `Unknown skill`。归档的 23 个原文件逐字节一致；新增载荷与本机来源在排除运行状态后逐字节一致。Gitleaks 扫描发布目录无密钥命中。matplotlib 生成的 SVG 示例保留原始路径空白，通过 `.gitattributes` 豁免这些生成物的空白检查。
